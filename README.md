## 🚀 Featured Projects

### 1. 📊 HR Analytics Dashboard — Power BI
> Analyzed 1,470 employee records · 16.12% attrition rate · 3 departments · 9 job roles

- Built multi-page Power BI dashboard with DAX measures for 5 KPI cards
- Identified R&D as highest attrition department (56.12%)
- Flagged 25–34 age band as the most at-risk segment for targeted retention

---

### 2. 🤖 AI-Powered JD Skill Analyzer — HTML / JS / Claude API
> Parses any job description and scores resume fit using Claude AI

- Extracts must-have, preferred, and bonus skills from any JD
- Returns fit score, matched/missing skills, and resume improvement tips
- Direct application of AI in HRM — tied to NPTEL certification

---

### 3. 📋 Recruitment Pipeline Tracker — Excel
> End-to-end tracker with 6 stages: Sourced → Screened → Interviewed → Shortlisted → Offered → Joined

- Auto-calculates time-to-hire and sourcing channel effectiveness
- Pivot Table dashboard for stage conversion and recruiter-wise performance
- Estimated ~40% reduction in manual tracking effort

---

### 4. ✅ Employee Onboarding Automation — Excel
> Dynamic onboarding tracker for new hires across IT, HR, and Operations

- 25+ checklist items with conditional formatting progress bars
- IF/COUNTIF formulas for automated status alerts by department
- Improves onboarding visibility and reduces follow-up time
